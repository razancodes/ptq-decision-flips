01Abstract

Post-training quantization (PTQ) is applied to language models with no safety objective in mind, yet it measurably shifts individual decision boundaries, including, in our case study, a model's refusal decision. We ask whether a first-order perturbation theory, one that can be estimated from forward passes alone before any quantization happens, can predict which decisions will flip. Treating quantization as a bounded weight perturbation, we calibrate a variance model against real per-format quantization error measured on six checkpoints and find that it holds within a factor of two. The matching zero-crossing flip criterion, however, under-predicts the observed flip rates by 3.5 to 337 times. We trace the gap to a decision boundary that sits away from zero, and show that a much simpler quantity, the pre-quantization margin itself, needs no perturbation model at all and still beats the theoretically motivated predictor by a wide margin (AUC 0.95 versus 0.71). We present this as a case study in where current first-order theory for PTQ works, where it breaks down, and why.

02Setup

One decision, one scalar margin

Refusal is decided largely at the first generated token [Qi et al., 2025], which makes it a clean test case for a perturbation theory: the decision has a scalar margin we can read with forward passes alone, and 4-bit quantization supplies a real, measurable perturbation.

m0(x) = z(“I”) − mean[z(“Sure”), z(“Certainly”), z(“Of”)]first token, fp16

A positive m0 favors a refusal opening. The subscript marks the unperturbed model; Δm is the change in the same margin on a quantized checkpoint.

The first-order theory

Treat quantization as a weight perturbation δWt per tensor, in the spirit of prior work on weight perturbations and margins [Tsai et al., 2021]. To first order,

Δm(x) ≈ Σt ⟨∇Wt m(x), δWt⟩ ⇒  SD(Δm) = g · αisotropic, zero-mean δW

We estimate the sensitivity g by injecting isotropic Gaussian noise of scale α · std(W) into every transformer linear weight, at α ∈ {0, .0025, .005, .01, .02, .04} with five seeds each: 62,400 margin measurements, forward passes only. A no-intercept linear fit has median R2 = 0.997. Separately, we measure each format's real error αequiv = RMS(Wquant − Wfp16) / std(Wfp16) directly from the checkpoint files, on the same tensors.

03What it predicts

The size of the shift, within a factor of two

Substituting each format's measured αequiv into SD(Δm) = g · αequiv predicts the observed spread on all six Falcon3 model-by-format cells. The median ratio of observed to predicted is 0.62.

04Where it breaks

Which decisions flip, missed by orders of magnitude

The matching flip criterion asks how likely a perturbation of that size is to carry the margin across zero, averaged over prompts:

P(flip) ≈ Φ(−|m0| / (g · αequiv))

Observed flip rates are 3.5 to 337 times higher than this predicts. The isotropic model is good enough for the magnitude of the perturbation, not for boundary crossing.

05What works instead

The margin you start with

Ranking prompts by m0, measured before any quantization and with no model of the perturbation, predicts which ones flip far better than the measured shift Δm does.

Across all three families

Within the fp16-refused stratum, where every break must originate, m0 reaches AUC 0.90 to 0.95 in each family. Intervals come from a prompt-clustered bootstrap with 2,000 resamples.

FamilyStratum nAUC95% CI0.80 — 1.00

A small first-token margin seems to mark a refusal that is only shallowly held, so a perturbation of the size quantization supplies is enough to tip it. We read m0 as a proximity measure for that property, and offer its performance as a target that a boundary-aware perturbation theory should explain.

06A note on decoding

Quantized checkpoints bring their own decoding

Each checkpoint repository ships a generation_config.json, and a pipeline that does not state its decoding inherits it. Before we audited this, the cells of our grid were decoding under different settings, so a format comparison was partly a sampling comparison.

Every flip counted on this page comes from greedy decoding, passed explicitly in every cell. The four cells that were genuinely greedy all along reproduce 400 of 400 replies across a Colab-to-Kaggle migration and a library-version change.

Code

Dataset

huggingface.co/datasets/razancodes/ptq-refusal-flips · gated

5,386 fp16-versus-quantized pairs with both replies, judge labels, flip direction, m0 and Δm, and blind human labels on all 267 flips (138 breaks, 129 restores). The prompts request harmful content, so access is granted for safety research.
